目前版本：0.1.0-preview.13（2026-11-21），持續打磨中的序章試玩版；公開企劃規格書修訂 15。中文名稱定為《心之燈》，英文暫譯 Heart’s Lantern。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；手機及實體手把尚待實機驗證。首次載入需要下載遊戲素材。

這次繼續調整主角的轉身承重、第一步換腳與收步銜接，跑姿略向前傾。轉身時握柄留在手中，杖頂退到頭後，減少遮住雙眼。提燈被暫停打斷時，腳步會從當下的抬腳位置與朝向接續收勢。居民停步會收完最後一步，工匠轉身時沿著槌柄換手。

注光沿用先提燈、再由燈心送出暖光的方式；微光抵達物件後，上方的火焰圖示依序亮起，已亮圖示保持原位。放開操作後不再投入下一滴，已送出的光仍會完成。電腦使用 E，觸控下滑後停住持續投入、抬指停止，通用手把使用 A。

第一盞居民心燈與守鐘人的燈亮起後，可以在東林面向苔石提燈，照出被遺忘的刻痕，親手開通「樹根舊徑」。提示會指向東林，發現後收起箭頭，守夜與救助仍優先。舊徑可往返村口與林間；路口有危險時暫不通行，穿越可以取消，日夜仍照常流轉。

開通舊徑後，可在林端再照見一處回聲，解鎖「留一聲鐘，照亮歸途」。白天到村西繩結，便能把既有每夜三響中的一響留給東欄外的回音燈，也可回到繩結取消。夜裡適合的來敵靠近時，親手敲響回音燈，使牠短暫現形；另外兩響仍由守鐘人自動使用，整夜合計最多三響。這是一條可略過的支線，無需額外貨幣，也不會加速入夜。未用的留聲在日出時結束。

男女居民的轉身、抱琴與工具交接，以及工匠伐木時鹿緩步讓開、工作進度放在樹根下的內容均保留。工坊修繕槌與琴屋豎琴仍會放在建築側架上，顯示真正尚未被領取的庫存，最多三件；居民領走後就少一件，保存再讀取也依原有庫存顯示。

男女都可招募、領工具或豎琴；兩種器具都有庫存時，男性 70% 偏好工具、女性 70% 偏好豎琴。缺貨回退、製作費用與既有職業維持原規則，庫存和領具偏好會保留。

互動燈火固定在物件上方，尚未開放的物件不顯示提示。林路的南瓜馬車可以修復並接應旅人；白天持琴人安撫動物，動物停步聽琴、留下燈露，再慢慢走開歇息。繁中、簡中與英文的小螢幕探索提示保留簡短呈現。

持琴居民回頭時動作仍較快，村燈旁的居民有時會與主角重疊。歡迎回報你在走跑、掉頭或添光時最想改善的一刻，本版本不代表全部動畫或多平台品質已完成驗收。
