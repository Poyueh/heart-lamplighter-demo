目前版本：0.1.0-preview.4，持續打磨中的序章試玩版。中文名稱定為《心之燈》，英文暫譯 Heart’s Lantern。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；手機及實體手把尚待實機驗證。首次載入需要下載遊戲素材。

本次修正快跑接揮杖與急停時的肢體銜接，調整居民分件與持物；靠近建築可見互動名稱、操作與點燈空槽。電腦使用 E，手機下滑後停住即可持續投入，抬指停止；空槽隨微光抵達填亮。公開企劃規格書隨本次試玩同步更新。
