目前版本：0.1.0-preview.8，持續打磨中的序章試玩版。中文名稱定為《心之燈》，英文暫譯 Heart’s Lantern。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；手機及實體手把尚待實機驗證。首次載入需要下載遊戲素材。

本次調整居民的領具偏好：男女都可招募與使用工具或豎琴。兩種器具都有庫存時，男性70%偏好工具、女性70%偏好豎琴；缺貨會改領可用器具，已就業居民保留工作。偏好會隨居民固定，不因讀檔重抽；小村不保證剛好符合比例。

持物改以實際槌柄握點連接手掌，手與槌子一同轉身及工作；調整自然垂握與工作銜接，移除領具時額外浮空的槌子圖示，並調整抱琴位置及手臂圖層。請特別觀察男女居民拿工具／琴、轉身和工作時的持握。正常速度自然度仍需要試玩回饋。前版鏡頭與互動範圍修正保留；部分更舊旅程的居民首次更新可能改用另一套既有外觀，其後固定。

保留先前的互動與故事內容：互動燈火固定在物件上方，移除遮住場景的大文字板，尚未開放的物件不顯示提示。電腦使用 E，手機下滑後停住持續投入，抬指停止；空燈芯隨微光抵達點亮。林路的南瓜馬車可以修復並接應旅人；白天持琴人安撫動物，動物停步聽琴、留下燈露，再慢慢走開歇息。公開企劃規格書同步更新。
