# 心燈師 / Heart Lamplighter

繪本風格的探索與守護遊戲。替人們點亮心中的燈火，再與他們一起守住夜晚。

- [開始 H5 序章試玩](https://poyueh.github.io/heart-lamplighter-demo/play/)
- [公開企劃規格書](https://poyueh.github.io/heart-lamplighter-demo/spec/)
- [試玩說明](https://poyueh.github.io/heart-lamplighter-demo/guide.html)

目前版本：0.1.0-preview.2，持續開發中的序章。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；實體手把型號、瀏覽器相容性及各平台實機品質仍在驗證。首次載入需要下載遊戲素材。

本次更新加入屈膝走跑、固定村燈傳火、可見的補光進度、居民豎琴與原創配樂試聽混音。企劃規格書同步至15章。

進度保存在目前瀏覽器，清除網站資料會移除紀錄。沒有帳號或雲端同步。

本倉庫只保存公開成品、玩家文件與網站部署設定。遊戲原始碼、美術原稿、內部資料和開發歷史保存在獨立私有倉庫。Release 附件提供 H5 成品及校驗碼，標籤僅指向本公開庫的提交。
