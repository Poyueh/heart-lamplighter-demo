# 心之燈 / Heart’s Lantern

繪本風格的探索與守護遊戲。替人們點亮心中的燈火，再與他們一起守住夜晚。

目前版本：0.1.0-preview.12，持續打磨中的序章試玩版。中文名稱定為《心之燈》，英文暫譯 Heart’s Lantern。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；手機及實體手把尚待實機驗證。首次載入需要下載遊戲素材。

第一盞居民心燈與守鐘人的燈亮起後，可以在東林面向苔石提燈，照出被遺忘的刻痕，親手開通「樹根舊徑」。本版讓提示指向東林，發現後收起箭頭，守夜與救助仍優先。舊徑可往返村口與林間；路口有危險時暫不通行，穿越可以取消，日夜仍照常流轉。

本版調整主角與居民的步行承重、肩手配合及披風下襬，讓身體和持物隨腳步共同銜接。注光會先提起燈，再由燈心送出暖光；微光抵達物件後，上方火焰圖示依序共鳴，已亮圖示保持原位。放開操作後不再投入下一滴，已送出的光仍會完成。

男女居民的轉身、抱琴與工具交接，以及工匠伐木時鹿緩步讓開、工作進度放在樹根下的內容均保留。正常速度下的整體自然度、轉身與手指細節仍在打磨。

繁中、簡中與英文的小螢幕探索提示縮短，保留主角的頭與燈。原生 640×360 畫面已檢查，手機實際顯示與操作仍待驗證。

工坊的修繕槌與琴屋的豎琴仍會放在建築側架上，顯示真正尚未被領取的庫存，最多三件；居民領走後就少一件，保存再讀取也依原有庫存顯示。

男女都可招募、領工具或豎琴；兩種器具都有庫存時，男性70%偏好工具、女性70%偏好豎琴。缺貨回退與製作費用維持不變；既有職業、庫存與領具偏好會保留，v52 另保存舊徑進度。前版的持物、鏡頭與互動範圍修正保留。

保留先前的互動與故事內容：互動燈火固定在物件上方，移除遮住場景的大文字板，尚未開放的物件不顯示提示。電腦使用 E，手機下滑後停住持續投入，抬指停止；空燈芯隨微光抵達點亮。林路的南瓜馬車可以修復並接應旅人；白天持琴人安撫動物，動物停步聽琴、留下燈露，再慢慢走開歇息。公開企劃規格書同步更新。
