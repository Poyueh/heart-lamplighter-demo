# 心之燈 / Heart’s Lantern

繪本風格的探索與守護遊戲。替人們點亮心中的燈火，再與他們一起守住夜晚。

目前版本：0.1.0-preview.7，持續打磨中的序章試玩版。中文名稱定為《心之燈》，英文暫譯 Heart’s Lantern。提供鍵鼠、觸控與通用手把操作原型，手機建議橫向；手機及實體手把尚待實機驗證。首次載入需要下載遊戲素材。

本次整理走路、快走與停步時的鏡頭：連續銜接取景，停止後保留前方視野，減少景物反向回拉。主角、湖面與添光光流同步畫面位置。物件依本體大小擴大操作範圍，居民與小物件也更容易靠近；按住添光維持原目標，走離範圍便停止，費用與存檔格式維持。

請特別試試連續走停、轉身，以及從建築兩側靠近並互動。鏡頭的實際舒適度仍需要你的回饋。居民外觀與職業分離、豎琴持握等前版調整保留；部分更舊旅程的居民首次更新可能改用另一套既有外觀，其後固定。

保留先前的互動與故事內容：互動燈火固定在物件上方，移除遮住場景的大文字板，尚未開放的物件不顯示提示。電腦使用 E，手機下滑後停住持續投入，抬指停止；空燈芯隨微光抵達點亮。林路的南瓜馬車可以修復並接應旅人；白天持琴人安撫動物，動物停步聽琴、留下燈露，再慢慢走開歇息。公開企劃規格書同步更新。

人物動作仍須依正常速度試玩感受繼續修整，本版本不代表全部動畫或多平台品質已完成驗收。
